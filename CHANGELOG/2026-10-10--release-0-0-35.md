## Release 0.0.35 — the version marker for the batch, one literal, no rider

### Changed
- `agenthub_go/fastmcp/config/version.go` — `ReleaseVersion` **"0.0.34" → "0.0.35"**. That one literal is the
  whole change: `/health` derives its version from it through `httpapp/http.go:160`
  (`const healthVersion = config.ReleaseVersion`), and the same value is what the MCP `initialize` serverInfo,
  the MCP status tool and the server records report, so there is one version identity rather than several.

### Why this deploy is owed
- Production already serves **0.0.34** (the lead's `/health` read at 20:02Z), so a deploy of this tree without
  the bump would report the version it replaced and could not be confirmed by version.
- The deploy is owed because **the task board is still unwritable**: `manage_task update` fails with
  `ERROR: column "subtask_id" of relation "task_events" does not exist (SQLSTATE 42703)`. The last boot fixed
  `user_seq` and the write moved to the next missing column. **`a0313d5f`, in this tree**, derives the
  `task_events` column ensurer from its `TableDef` — `EnsureTableColumns` iterates `table.Columns`, adds what
  is missing, then verifies presence and type — which closes the class rather than the column. The lead's
  one-line emergency option, the owner's call alone, is
  `ALTER TABLE task_events ADD COLUMN IF NOT EXISTS subtask_id UUID;`.

### Why it is the last commit of the set
- The bump must cover the tree it marks, so it lands **after** the content it names. If a commit lands after it,
  the bump moves to that commit or the deploy waits — the rule written in the file itself.

### Verified
- The literal is the only change; `gofmt -l` on the file is clean; `go build ./fastmcp/config/` is rc 0.
- The next deploy's acceptance is **not** this commit: `/health` must read **"0.0.35" from a new process**, and a
  status change must be **read back** on a real task — the write-level probe this incident added, because
  version and uptime alone are what let the last deploy pass while the write path was broken.
