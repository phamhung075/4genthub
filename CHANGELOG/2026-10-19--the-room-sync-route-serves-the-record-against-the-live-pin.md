# The room sync route serves the record against the live pin, read-only

## Changed

- `agenthub_go/fastmcp/server/httpapp/seat_status_mount.go`: one new route,
  `GET /api/v2/rooms/{room}/sync` (user token, tenant-scoped by the caller's user id), one handler
  `handleRoomSync` and one pure helper `roomSyncRows`. It answers
  `{success, room, seats:[{seat, expected_hash, pinned_hash, machine_id, reported_at, sync}]}` where
  `expected_hash` is the newest resolved snapshot's hash (no record reads as empty) and `pinned_hash`
  is the running hash the bridge reports - the `/machines` spelling, not the cloud's intended hash -
  and `sync` is `seatsync.Sync(pinned, expected)`: `unknown` when either hash is empty, `in_sync`
  when equal, else `drift`. The reduction is the room's seats only: more than one machine reporting a
  room+seat keeps the newest `reported_at`, a tie keeps the smallest `machine_id`, rows sort by seat
  key, and a seat no machine reports is absent - absence is never `in_sync`.
- The route reads the same `seatStatusSource.List` the two existing status routes read: the record
  hash is the LEFT JOIN's, so the room view and `GET /api/v2/machines` cannot disagree by
  construction. It never calls `ResolveSeat`: resolving writes a snapshot, so inspecting drift through
  the seat route would create the record it was inspecting. `GET /api/v2/machines` and `POST
  /api/v2/seat-status` are unchanged.
- `agenthub-frontend/src/docs/apiReference.ts`: regenerated by `go run ./cmd/apirefgen` (156 routes,
  9 tools) - the committed artefact gains the route, and `internal/apiref/committed_artefact_test.go`
  stays green.

## Tested

- `go test ./fastmcp/server/httpapp/ -run TestRoomSyncReadsTheRecordAgainstTheLivePin -count=1` -> ok;
  the test drives two machines over two rooms and asserts `in_sync`, `drift`, both `unknown` shapes,
  newest-wins, the machine-id tie, seat-key ordering, the newest `reported_at`, and that the other
  room's seat does not appear.
- `go test ./fastmcp/server/... -count=1` -> ok.
- `go test ./internal/apiref/ -count=1` -> ok (the regenerated artefact matches the producer).
