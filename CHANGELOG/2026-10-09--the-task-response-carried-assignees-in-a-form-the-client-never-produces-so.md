## The task response carried assignees in a form the client never produces, so every comparison missed - the stored value now goes through untouched

### Fixed
- **`agenthub_go/fastmcp/task_management/application/dtos/task/task_response.go:116-131` — the assignee rewrite is DELETED, not adjusted.** The REST DTO stripped the leading `@` from every assignee and appended `-agent` when the name did not already end in it. The stored form is `@<seat_key>` or `@<role>` — `normalizeAssignee` (attaches `@`) at `entities/task.go:320-337`, reached through `NormalizeAssignees` (`:443-462`) — and that is exactly what the client offers and compares: the picker builds `` `@${seat.seat_key}` `` (`agenthub-frontend/src/api.ts:366`), the edit dialog toggles seats by comparing the raw stored string (`src/components/TaskEditDialog.tsx:169`), the list filter uses `task.assignees.includes(filters.assignee)` (`src/hooks/useTaskFilters.ts:62`), and the response validator **warns when the `@` is missing** (`src/utils/responseValidator.ts:148-152`). So a REST-sourced `go-dev-agent` could not match the picker's `@go-dev` — for **any** name, not only a role ending in `-research` (row 0adcfe7f). The stored slice is now carried through unchanged.
- **The same strip existed at a SECOND site, inside the domain: `entities/task.go` `Task.ToDict` and `entities/subtask.go` `Subtask.ToDict` each resolved every assignee through the `entities.AgentNameResolver` seam.** Both now carry `Assignees` as stored, the same rule as `labels`/`subtasks` beside them. Fixing only the DTO would have left the MCP/`ToDict` responses still mismatched — the two writers had to change together.
- **That was the seam's last reader, so the seam goes with it: `entities.AgentNameResolver` (var + doc), the two nil-guard error paths, the `init()` registration in `application/use_cases/agent_mappings.go`, and `TestResolverRegistered`.** Exported-shape change, verified by reference search: after the change, `ResolveAgentName`, `IsDeprecatedAgent` and `DeprecatedAgentMappings` in that same file have **no non-test reader left** (`grep -rn --include=*.go 'ResolveAgentName\|IsDeprecatedAgent\|DeprecatedAgentMappings'` → 3 files: the file itself, its test, and stale `.gotmp` build artifacts). **Left in place and reported rather than bundled** — a 131-line module whose removal is its own call.
