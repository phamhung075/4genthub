DOCS. Documentation lives in ai_docs/. Check ai_docs/index.json for an existing document before writing a new one; hooks regenerate the index.

Rules:
- ai_docs subfolders use kebab-case (api-integration, setup-guides). _absolute_docs and _obsolete_docs are the only exceptions.
- Only five .md files are allowed in the repository root: README.md, CHANGELOG.md, TEST-CHANGELOG.md, AGENTS.md and CLAUDE.local.md. Every other document goes under ai_docs.
- Write documentation only when asked, and test any code example before documenting it.

Changelogs (Keep a Changelog format, include file paths, impact and testing):
- CHANGELOG.md in the root for project-wide changes.
- agenthub-frontend/CHANGELOG.md for frontend-only changes.
- TEST-CHANGELOG.md when test files change.
Never create a CHANGELOG.md in other directories.

agenthub_go/NEXT_GEN.md is the running backlog and decision record for new features after the Go port: tick a box only when its check is met, and record owner decisions with the date.
