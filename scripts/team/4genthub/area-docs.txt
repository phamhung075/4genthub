DOCS. Documentation lives in ai_docs/. Check `git ls-files 'ai_docs/**/*.md'` for an existing document before writing; the tracked tree is the index.

Rules:
- ai_docs subfolders use kebab-case (api-integration, setup-guides); _absolute_docs and _obsolete_docs excepted.
- Only three .md files are allowed in the repository root: README.md, AGENTS.md and CLAUDE.local.md. Every other document goes under ai_docs.
- Docs are minimal: only durable information a reader needs and cannot get from the code or git log. No reports, plans, reviews, status notes or history paragraphs.
- Write documentation only when asked, and test any code example before documenting it.

Change records: no changelog file of any kind. The commit message is the record (what was wrong, what changed, how it was tested). Plans, backlog, decisions and status live in 4genthub tasks and context.
